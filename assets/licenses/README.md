# Desktop references

The responsive home-grid sizing algorithm in `src/gui/home.rs` is adapted from
[quiet-md](https://github.com/s1dashu/quiet-md), copyright (c) 2026 s1dashu,
under the MIT license reproduced in `quiet-md.txt`.

The document typography, bounded Markdown thumbnail design, and short UI transitions
also follow quiet-md's approach while
using Nole's shared parser and semantic theme. Desktop icons use [Lucide](https://lucide.dev), distributed under the ISC license
reproduced in `lucide.txt`. The embedded SVG assets and source revision are in
`assets/icons/lucide/`.
